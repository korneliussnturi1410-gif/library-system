# Library System

## Description

Library System adalah aplikasi sederhana yang dibuat menggunakan Laravel sebagai framework PHP. Project ini dibuat untuk memenuhi tugas mata kuliah Pemrograman Web Framework.

## Requirements

- PHP
- Composer
- Laravel
- MySQL
- XAMPP
- Git
- Visual Studio Code
- Web Browser

## Installation

1. Clone repository dari GitHub.

2. Masuk ke folder project:

```bash
cd library-system
```

3. Install dependency menggunakan Composer:

```bash
composer install
```

4. Buat file `.env` berdasarkan `.env.example`.

5. Konfigurasikan database pada file `.env`.

6. Buat database dengan nama `library_system`.

7. Jalankan migration:

```bash
php artisan migrate
```

8. Jalankan server Laravel:

```bash
php artisan serve
```

9. Buka aplikasi melalui browser pada `http://127.0.0.1:8000`.
